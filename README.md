Selenium POM Automation Project

Project Description

This project is an automation testing framework developed using Python, Selenium WebDriver, and Pytest with the Page Object Model (POM) design pattern.

Tools and Technologies

- Python
- Selenium WebDriver
- Pytest
- PyCharm

Features

- Login page automation
- Registration page automation
- Reusable page classes
- Test execution using Pytest

Project Structure

- HomePage.py
- LoginPage.py
- RegisterPage.py
- conftest.py
- lib.py
- test_login.py
- test_register.py

Purpose

The main purpose of this project is to automate login and registration functionalities using Selenium and Python.
